# ⚙️ How a Website Works

<p align="center">
  <img src="images/request-response-cycle.png" alt="Request Response Cycle" width="700">
</p>

```text
Browser
   ↓
Request Sent
   ↓
Web Server
   ↓
Database
   ↓
Response Returned
   ↓
Browser Displays Website
```

### Process

1. User enters URL
2. Browser sends request
3. Server processes request
4. Database provides data
5. Server sends response
6. Browser renders webpage

# 🌍 HTTP Request & Response

| Method | Purpose       |
| ------ | ------------- |
| GET    | Retrieve Data |
| POST   | Create Data   |
| PUT    | Update Data   |
| DELETE | Remove Data   |

Example:

```http
GET /students
POST /register
PUT /student/1
DELETE /student/1
```
